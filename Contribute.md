# Suggesties of wijzigingen? 

Suggesties en wijzigingsverzoeken kunnen doorlopend toegevoegd worden via Github Issues. Elk kwartaal evalueert een Podiumkunst.net beheerteam de verzoeken. 

## Suggesties en wijzigingsverzoeken via Github

- Maak een [nieuw issue aan](https://github.com/PodiumkunstNet/ApplicationProfileRDA/issues)
- Omschrijf de suggestie of de wijziging
- Voeg wanneer mogelijk en van toepassing een oplossing, in tekst of via een pull request

## Beoordeling

- Elk kwartaal beoordeelt een Podiumkunst.net beheerteam de verzoeken
- Deze beheercommissie kent een gewicht toe:
  - small (verzoek is eenvoudig door te voeren)
  - medium (verzoek doorvoeren kost gemiddeld tijd of overleg  met iemand van buiten het beheerteam is nodig)
  - large (verzoek kost veel tijd en wordt opgepakt door een tijdelijke werkgroep)
